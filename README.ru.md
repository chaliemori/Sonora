Простой оффлайн-плеер на Jetpack Compose и Media3. Без рекламы, аналитики и доступа в сеть.

## Что умеет

- Воспроизводит локальные треки (FLAC, WAV, MP3, AAC, M4A, OGG, OPUS) в фоне с управлением из шторки.
- Подбирает цвета интерфейса из обложки текущего трека, системной темы или выбранного цвета, есть чистый чёрный AMOLED-режим.
- Волнистый ползунок прогресса, закрытие плеера свайпом вниз и переключение треков свайпом по обложке.
- Показывает формат, битрейт и частоту дискретизации прямо в плеере.
- Сканирует музыку на телефоне и в выбранных папках, есть поиск, сортировка, избранное, свои плейлисты и таймер сна.
- В горизонтальном режиме перестраивается под широкий экран, а боковую панель можно поставить слева или справа в настройках.

## Сборка

Нужны Android SDK (API 35) и JDK 17:

```bash
git clone https://github.com/chaliemori/Sonora.git
cd Sonora
gradle assembleDebug
```

Для релизной сборки (подписывается через `release.properties` и `release.keystore`, если они есть в папке):

```bash
gradle assembleRelease
```
